# MedHedi19 Terminal Portfolio

A small interactive terminal-style portfolio built with plain HTML, CSS and JavaScript.

## Run locally
Open `index.html` in your browser.

## Publish with GitHub Pages
Your profile README repository (`MedHedi19`) and your website repository serve different purposes.

1. Keep `MedHedi19` for your GitHub profile README.
2. Create a **second public repository** named exactly `MedHedi19.github.io`.
3. Upload `index.html`, `style.css` and `script.js` to the root of that new repository.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then Save.
7. GitHub Pages will publish the site at `https://medhedi19.github.io` after deployment finishes.

## Personalize before publishing
Edit `script.js`:
- Replace `YOUR_EMAIL@example.com` with your public contact email.
- Replace the LinkedIn placeholder URL with your profile URL.
- Review the education wording and dates.
- Add links to your project repositories.
- Adjust the skills list so it reflects tools you can confidently discuss.

The ASCII portrait is included in `index.html` as text. Keep it inside the `<pre class="portrait">...</pre>` element so its spacing is preserved.
